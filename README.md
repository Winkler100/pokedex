# pokedex
A Pokédex é um dispositivo do universo Pokémon criado para identificar, registrar e armazenar informações sobre as diferentes espécies de Pokémon. Ela funciona como uma espécie de enciclopédia digital, permitindo que os treinadores consultem informações sobre os Pokémon que encontram durante suas aventuras.

Cada Pokémon possui um número específico, além de um nome, aparência, tipos e diversas outras características. A Pokédex organiza essas informações, tornando mais fácil identificar cada espécie e conhecer melhor suas características.

Nos jogos da franquia Pokémon, a Pokédex também está relacionada ao progresso do jogador. Conforme o treinador encontra e captura novos Pokémon, novas informações são adicionadas ao registro. Assim, completar a Pokédex se torna um dos objetivos para muitos jogadores.

Além disso, a Pokédex pode apresentar informações diferentes dependendo da região e da geração dos Pokémon. Por isso, existem várias versões do dispositivo ao longo da franquia, cada uma com diferentes recursos e informações.

De forma geral, a Pokédex pode ser entendida como um banco de dados dos Pokémon, criado para organizar informações de maneira rápida e acessível. Ela representa uma das principais ferramentas utilizadas pelos treinadores para pesquisar, identificar e conhecer os Pokémon encontrados em suas jornadas.

O código desenvolvido utiliza HTML, CSS e JavaScript para criar uma Pokédex interativa. O HTML é responsável pela estrutura da página, contendo os elementos como imagem, nome, número do Pokémon, campo de pesquisa e botões de navegação.

O CSS é utilizado para definir a aparência da Pokédex, organizando os elementos, adicionando estilos e deixando a página visualmente semelhante a uma Pokédex.

Já o JavaScript é responsável pela interação e funcionamento do projeto. Ele permite pesquisar Pokémon, atualizar suas informações e navegar entre eles através dos botões Prev e Next.

O código também utiliza a PokéAPI, que fornece os dados dos Pokémon. Dessa forma, quando o usuário pesquisa ou navega para outro Pokémon, o JavaScript faz uma requisição à API e apresenta as informações recebidas na tela.
